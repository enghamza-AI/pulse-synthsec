> *Most ecommerce tools ask "will this customer churn?" — for physical products, the real question is "when will they buy again, and is it worth chasing?"*

## What is this

Pulse is a synthetic-data demo of [SynthSec's](#author) customer intelligence methodology for ecommerce: it segments customers into behavioral groups (VIP, regular, at-risk, one-time) and predicts, in days, when each customer is realistically likely to buy again — instead of applying a generic 30-day cutoff that fits almost no real product.

It is a portfolio piece, not a client deliverable. All data is synthetic and clearly labeled as such — no real client data exists yet, and none is used here.

## The problem

A naive approach treats every customer the same way ("email everyone 30 days after purchase") or treats ecommerce like a subscription business ("predict churn/no-churn"). Neither fits: a mattress buyer and a t-shirt buyer have completely different natural repurchase rhythms, and physical-product customers don't "cancel" — they just quietly stop coming back, on their own schedule. Naive timing wastes budget and annoys customers either way.

## What it does

```
synthetic order CSV
        │
        ▼
  pandas cleaning            → drop bad rows, cap outlier order values
        │
        ▼
  feature engineering        → recency, frequency, monetary, interpurchase gaps (per customer)
        │
        ▼
  K-Means segmentation       → VIP / regular / at-risk / one-time (unsupervised)
        │
        ▼
  repurchase-window model    → RandomForestRegressor predicts days-to-next-purchase (supervised)
        │
        ▼
  recommended actions        → plain-English next step + urgency, per customer
        │
        ▼
  Streamlit dashboard        → deployed on Hugging Face Spaces
```

## Key concepts

| Concept | 
|---|---|
| RFM-style feature engineering | Recency, frequency, monetary total collapsed to one row per customer via groupby+agg |
| K-Means segmentation | Unsupervised clustering into 4 behavioral segments, named from centroid stats, not guessed |
| Censored supervised label | One-time buyers have no "next purchase" to learn from — excluded from training, still scored |
| RandomForestRegressor | Predicts days-to-next-purchase per customer from behavioral features |
| Business-rule translation layer | `recommendations.py` turns segment + score into a plain-English action, separate from the model code |

## Dataset

100% synthetic, generated by `src/synthetic_data.py`. Each customer has a hidden "true repurchase cadence" drawn from a lognormal distribution, used to simulate realistic (noisy, irregular) order timestamps — never exposed as a feature, only as the process that generates the data. This isn't a toy dataset with obviously separable clusters; the segments have to be recovered from noisy behavioral signals the same way they would from a real export, which is the whole point of using it as a methodology demo.

## Results

Numbers from the bundled demo dataset (2,000 synthetic customers):

| Metric | Value |
|---|---|
| Customers segmented | 2,000 |
| Segments found | 4 (VIP, regular, at-risk, one-time) |
| Silhouette score | 0.49 |
| Repurchase-window model MAE | 8.4 days |
| Customers with a supervised label | ~41% (2+ orders) |
